## 0.3.0

- Initial release. Riverpod state inspector: provider browser with live values,
  a `prev → next` write log, per-provider history, CHANGE/VALUE/DIFF (tree +
  split) detail, and the ignore-pattern filter. `BuoyRiverpodObserver` backend,
  desktop sync adapter (`riverpod` tool id, Jotai wire shapes), and events-
  timeline source.
